# TONY — Voice Finder Website

This is the mobile-first landing page for the TONY Android app.

## Put the APK here
`downloads/TONY-v1.0.0.apk`

The Download buttons already point to that exact path.

## Publish
Upload this folder to a GitHub repository and enable GitHub Pages.

## Included real app assets
The `assets/` folder contains the supplied TONY logo and the four supplied screenshots:
- setup.webp
- home.webp
- settings.webp
- how-it-works.webp

Review the privacy page and production claims before publishing.
